## General Principles

When altering or adding a new feature/element, match the current design UI and UX.
When user input is required, avoid typing and other sources that can lead to common mistakes and instead prefer selecting from available known types like drop-down and or toggles et cetera.

## Design Principles

Always use Title Case for headers and labels.
Never use the left border UI element.
Never use FULL CAPS anywhere ever. 
Prioritise reusability when it comes to styling and design, enabling downstream additions to easily match the current style


## Project Specific Principles

Terminology:
- Notepad = refers to the actual block of the note where the text/typing takes place
- Menubar = refers to the left most menu item bar
- Sidebar = refers to the location of the menubar's items, where the navigation of these items takes place (folder, notes, reminder, etc)
